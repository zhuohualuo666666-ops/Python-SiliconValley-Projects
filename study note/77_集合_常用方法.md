<!-- 77_集合_常用方法 -->

# 集合A.difference(集合B)：
作用：找出集合A中，不同于集合B的元素（集合A 与 集合B 都不变）
返回值：一个新的集合（集合A中，不同于集合B的元素组成）

# 集合A.difference_update(集合B)：
作用：从集合A中，删除集合B中存在的元素（集合A会被修改，集合B不会）

# 集合A.union(集合B)：
作用：合并两个集合，集合A 和 集合B 都不变
返回值：一个新的集合（包含集合A 和 集合B中的所有元素）

# 集合A.issubset(集合B)：
作用：判断集合A是否为集合B的子集
如果 集合A的所有元素都在集合B中，那就返回True，否则返回False

# 集合A.issuperset(集合B)：
作用：判断集合A是否是集合B的超集
如果集合A中，包含了集合B中的所有元素，那就返回True，否则返回False

# 集合A.isdisjoint(集合B)：
作用：判断集合A和集合B是否没有交集
如果没有交集，返回True；只要有一个公共元素，就返回False
