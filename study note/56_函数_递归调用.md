<!-- 56_函数_递归调用 -->
递归指函数直接或间接调用自己
函数一经调用，Python 会为这次调用创建栈帧并压入调用栈

def welcome(n):
    if n > 1:
        welcome(n - 1)
    print(f'你好啊{n}')
welcome(3)


def welcome(n):
    print(f'你好啊{n}')
    if n > 1:
        welcome(n - 1)
welcome(3)

这两段代码打印时机不同调用深度相同：
约定：函数调用时，Python 会为这次调用创建一个栈帧，压入调用栈；函数返回时，对应栈帧弹出。
[ F3, F2, F1]
表示调用栈，用F3 表示 welcome(3) 的栈帧，F2 表示 welcome(2)，F1 表示 welcome(1)，右边是栈顶。
·第一段代码栈变化：
[F3]
[F3, F2]
[F3, F2, F1]   # 最大深度，3 层 welcome 栈帧
[F3, F2]       # 打印 1,F1 出栈
[F3]           # 打印 2,F2 出栈
[]             # 打印 3,F3 出栈
·第二段代码栈变化：
[F3]            # 打印 3
[F3, F2]        # 打印 2
[F3, F2, F1]    # 打印 1，最大深度 3 层 welcome 栈帧
[F3, F2]        # F1 出栈
[F3]            # F2 出栈
[]              # F3 出栈


注意:第二段代码welcome(3)执行到welcome(n - 1)这一句时，welcome(3)未执行完，而是先去执行welcome(2)，welcome(3)还在栈中
