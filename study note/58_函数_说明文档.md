·定义一个函数：
def add(n1,n2):
    return n1 + n2

·准备在三个双引号中添加注释：
def add(n1,n2):
    """"""
    return n1 + n2

·三个双引号中按回车，生成注释格式：
def add(n1,n2):
    """
    
    :param n1: 
    :param n2: 
    :return: 
    """
    return n1 + n2

·填写上参数作用，函数功能
def add(n1,n2):
    """
    计算两个数相加结果
    :param n1:第一个数
    :param n2: 第二个数
    :return: 二者相加的结果
    """
    return n1 + n2
