集合分可变集合，不可变集合
内部元素无序，不能通过下标访问元素，会自动去除重复元素

非空可变集合定义方法：用花括号
s1 = {10, 20, 20, 30, 40, 40, 50, 60, 60, 70, 80, 90, 100}
s2 = {'你好', 'hello', '你好', 'atguigu', '北京'}
s3 = {10, '你好', True, 1, 12.4}

空可变集合定义方法：用set()函数（不能用花括号，因为直接写{}定义为字典）
s1 = set()

不可变集合定义方法：用frozenset函数
s1 = frozenset([10, 20, 30, 40, 50])
s2 = frozenset((10, 20, 30, 40, 50))
s3 = frozenset('hello')
s4 = frozenset()

集合中不能嵌套可变序列集合，但可以嵌套不可变序列集合（集合元素必须可哈希）：
s1 = {10, 20, 30, 40, 50}
s2 = frozenset({100, 200, 300, 400, 500})
l1 = [666, 777, 888]
t1 = ('hello', 'atguigu', '北京')

# s3 = {11, 22, 33, s1}  # 报错
s3 = {11, 22, 33, s2}  # 没问题
# s3 = {11, 22, 33, l1}  # 报错
s3 = {11, 22, 33, t1}  # 没问题
